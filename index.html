Pertanyaan yang Sering Diajukan

Bagaimana cara mengaktifkan akun setelah mendaftar? +
Setelah mendaftar, Anda akan diarahkan ke halaman pembayaran untuk mentransfer biaya langganan sesuai paket dan mengunggah bukti transfer. Super Admin akan memverifikasi dan mengaktifkan akun Anda secara instan.
Apakah data properti saya aman dan tidak tercampur pemilik lain? +
Ya, 100% aman. KostHub OS menggunakan arsitektur multi-tenant terisolasi berbasis kode pemilik unik. Hanya Anda dan staf resmi Anda yang dapat melihat dan mengelola data tersebut.
Bisakah saya meng-upgrade paket jika jumlah kamar bertambah? +
Tentu. Anda dapat menghubungi Super Admin kapan saja untuk upgrade dari Paket Starter ke Pro atau Enterprise tanpa kehilangan riwayat data transaksi dan penyewa yang sudah ada.
